# AI 日报：2026年10月08日 | 五维「算账日」：单价砍九成、预算砍十倍、检测每天十次

昨天（10-07）的关键词是**主权**——谁能自己造、自己审、自己付钱、自己信、自己跑。今天，主题翻到主权之后必然被问出的那一步：**既然自己干了，这笔账怎么算**。

算账不是少花钱，而是把每一分钱花在结构性便宜的地方。今天五条线分别给出了五种算法：

- ⚡ **模型层**：Claude Haiku 5.5 把 10 万 token 以内的请求价格砍掉 90%，OSWorld 电脑操作反超 GPT-6 Luna
- 💸 **采购层**：微软把员工月度 AI 支出上限从 10 万美元砍到约 1 万美元，Meta 砍半 Claude Code 用户但账单没降
- 🔍 **溯源层**：SynthID 检测器全球开放，代价是每个账号每天约 10 次配额
- 🎛️ **交互层**：GPT-6 Intelligent UI 用可操作组件替代大段文本，减少 token 往返
- 📦 **开源层**：Hermes Agent 把 2400 万次 clone 与全球 2.5% 的 token 用量，变成 15 亿美元估值的企业私有部署生意

## ⚡ Claude Haiku 5.5：小模型第一次站到 agent 架构的承重位置

**事件概要**：10 月 7 日，Anthropic 发布 Claude Haiku 5.5，定位「史上最快、最便宜、能力最强」的小模型，面向高并发、成本敏感的任务（摘要、上下文压缩、数据库查询、分类），并明确它作为 Opus 5.5 / Sonnet 5.5 的 subagent 搭档。

**关键细节**：

- **价格**：平均比 Haiku 4.5 低约 75%；10 万 token 以内请求低 **90%**，超过 10 万 token 低 50%——而上一代 90% 的请求都落在 10 万 token 以内档。每百万 token：输入 $0.10 / $0.50，输出 $0.50 / $2.50，缓存读取 $0.01 / $0.05（Haiku 4.5 分别是 $1.00 / $5.00 / $0.10）
- **性能**：OSWorld 2.1 离线子集 **72.4%**（Haiku 4.5 = 15.7%，GPT-6 Luna = 48.9%，Sonnet 5.5 = 83.9%）；GDPval-AA v2.1 职业能力 **1620**（4.5 = 735）；Humanity's Last Exam 无工具 45.9%（4.5 = 10.2%）；Terminal-Bench 4.0 命令行 agentic 编码 39.2%（4.5 = 0.0%，Sonnet 5.5 = 70.6%）；Chartography 视觉推理 46.4%（4.5 = 6.4%）
- **首个 Haiku 级「可调努力程度」**（low/med/high/xhigh/max），用户可以在成本与智能之间按任务动态调档
- **客户实测**：Asana 任务完成延迟降超 30%、单轮推理快 2.5 倍；HubSpot CRM 模拟门户套件拿到史上最高分 92.8%；Box 高 11 分且约一半延迟；AlphaSense 400 条文档查询 0.84 vs 0.76；Devin Fusion 用 Haiku 5.5 当 sidekick 拿到 FrontierCode 66.2
- **配套降价**：Sonnet 5.5 缓存读取减半（$0.20 → $0.10 每百万 token），因缓存读取占 token 消耗大头，多数 agentic 任务成本降约 20%；Max 5x / 20x / Team 用户每月分别获 $100 / $200 / 至多 $500 的 API 额度；Python 与 TypeScript SDK 新增 computer use 与 browser use beta
- **安全**：misalignment 评估与滥用合作意愿较 4.5 大幅改善；网络安全护栏比 Sonnet 5.5 更宽（允许更多防御任务，仍拦截渗透测试），生物护栏与 Sonnet 5 / 5.5 / Opus 5 对齐；全平台上架（AWS / GCP / Azure），模型 ID `claude-haiku-5-5`

**深度分析**：Haiku 4.5 在 Terminal-Bench 上的得分是 **0.0%**——上一代小模型在 agentic 编码上几乎交白卷；Haiku 5.5 跳到 39.2%，这是质变而非改良。更值得注意的是 OSWorld：电脑操作是最吃 token 的场景，最便宜的模型（72.4%）反而排在 GPT-6 Luna（48.9%）之前。当「便宜」和「能干 agent 活」第一次在小模型上重合，多 agent 架构的经济模型就变了：Opus 做规划、Haiku 做执行不再是成本妥协，而是最优解。这正是「主权日」的下一问——自己造模型之后，每个 subagent 调用都在烧钱，Haiku 5.5 把这笔账单砍掉一个数量级。而缓存减半 + 月度 API 额度是同一笔账的另一面：不只是卖模型，是给建 agent 的人发补贴，把开发者生态锁进自家计费层。

## 💸 Meta 与微软同时砍员工 AI 预算：用户砍半，账单没砍

**事件概要**：据 The Information 10 月 5 日报道，Meta 与微软都在显著削减员工对 Anthropic Claude 的使用，转向自研编码工具——微软转向 GitHub Copilot 与 OpenAI 框架，Meta 转向自研的 MetaCode 与 Muse Code。这是采购行为而非技术判断。

**关键细节**：

- **微软**：云与 AI 部门员工月度 AI 支出上限从 **$100,000 砍到约 $10,000**（多数情况，10 倍降幅）；此前预计内部对 Anthropic 技术的年化支出将超 **$10 亿**，该预期已下调逾三分之一
- **代价是探索空间**：这些数字是支出天花板而非实际花销，但管理层的指令让工程师「自由探索不同模型」的余量被一次性关掉
- **Meta**：Claude Code 内部用户从年初约 **60,000 掉到约 30,000**（裁员是因素之一，但报道指主因是战略转向自研）；自研 MetaCode 已有 30,000+ 内部用户，Muse Code 有 6,000+ 员工用户，8 月已开始外部客户测试
- **钱没少花**：转向期间，Meta 在 **28 天内仍向 Claude Code 支付超 $1.05 亿**——用户数腰斩，账单没有腰斩
- **客户侧不受影响**：微软企业平台上客户对 Anthropic 模型的支出仍在上升；Anthropic 年化收入节奏约 **$65B**，需求未减

**深度分析**：这是「算账日」最硬的一条。限制的逻辑不是「Claude 不好用」，而是「自己人用别人的模型，每一分钱都在给对手的研发经费」。$100k → $10k 的 10 倍降幅，把「采购主权」写进了预算系统。但 Meta 那条 28 天 $1.05 亿的数字更值得玩味：用户砍半而账单不动，说明剩下的用量是硬需求——要么任务质量替代不了，要么迁移成本高于账单本身。**「少用」和「少花」是两件事**，这正是企业 AI 采购在 2026 年的真实处境。对安全团队还有一层常被忽略的成本：换工具不换风险。Claude Code 此前被披露的未授权执行与 API key 窃取漏洞、微软修掉的 RoguePilot（GitHub Issue 里嵌入恶意指令即可接管仓库）都证明，风险跟着「自动访问敏感文件、命令与凭证」这个能力走，不跟着品牌走——迁移本身要重新付一遍安全验证的账。

## 🔍 SynthID 检测全球开放：第一次有一个公共入口，但每天只能查十次

**事件概要**：10 月 7 日，Google 宣布新版 SynthID 检测器支持所有合作伙伴的水印，并上线全新 synthid.com 向所有人开放。此前圈外人想查 SynthID 只能在 Gemini 里问，而模型的回答经常令人困惑。

**关键细节**：

- **规模**：仅 Gemini 一家，SynthID 已集成进超 **1800 亿**张图片与视频，以及约 **240,000 年**时长的音频
- **跨厂支持**：新版检测器支持 Google、OpenAI、Nvidia、Kakao 的水印，**Apple 即将加入**；不再需要分别访问各家检测器——以前 Google 的检测器连 ChatGPT 图片上的 SynthID 都认不出
- **受控的公共品**：需登录（Google / OpenAI / Apple 账号），每用户每天约 **10 次**图片、视频、音频检查配额；Google 工程师明确告诉 Ars，限制访问是**为了防止有人把检查接口用来开发 SynthID 去除工具**；如果连续检查多张高度相似的图片，系统可能提前锁定（疑似在调参找绕过）
- **信息量缩水**：公开站点只告诉你「是否检测到水印」，不再像内部工具那样高亮图片中携带 SynthID 像素的区域
- **覆盖率天花板**：Meta 用的是另一套水印方案，部分厂商完全没有水印，开放权重模型在本机生成的逼真内容连元数据标注都没有；网站会挂免责声明承认这一点。Google 自己也承认，相反方向可能才是正解——用 C2PA 之类的密码学技术在内容创作时就标注「这是真的」，Pixel 是少数在做的设备

**深度分析**：这是 10-06「溯源日」与 10-07 textGrain 的直接后续。欧盟规则落地后，检测基础设施第一次从「各家自留地」变成「一个公共入口」——跨厂聚合这件事本身比任何单家水印的进步都重要，因为检测的价值等于网络的覆盖面。但「公共」是有限度的公共：10 次/天 + 强制登录，说明 Google 把 detector 当成受控接口来设计，而不是开放 API。原因很直接：**每次查询都返回「水印还在不在」，就是一个免费的强化学习奖励信号**，查得够多就能训出去水印的模型。这个设计与昨天 textGrain 的困境完全同构——可检出性与抗去除性是天然矛盾，任何向公众开放的检测器都必须在「有用」和「不当 oracle」之间定价。结构性出路可能是 C2PA 那条反路：不证明「这是假的」，而是证明「这是真的」，把成本转移到拍摄设备端，让检测不再是博弈对象。

## 🎛️ GPT-6 与 Intelligent UI：对话框开始长出应用的原件

**事件概要**：OpenAI 随新的 GPT-6 模型在全球 ChatGPT 推出 Intelligent UI，把大量可交互视觉直接嵌入对话，官方定位是「让学习复杂主题更容易」。

**关键细节**：

- **不是平面图**：界面里出现的是可点按钮、针对具体任务的定制计算器、交互图表、可编辑图形、多日徒步地图——用户可以直接在上面操作，而不是只看
- **官方表述**：产品经理 Aarush Selvan 承认「ChatGPT 至今主要是文本界面」，但「最有用的答案不只是文本」
- **演示案例**：问「机翼如何产生升力」会立刻生成多张解释图解；另有食谱视觉、自行车机械图、个人储蓄计算器
- **可定制**：用户可以像调聊天个性一样调低视觉量
- **分发节奏**：Pro / Plus / Business / Enterprise 全球推出，周四（10-08）开放给免费与 Go 层

**深度分析**：Intelligent UI 表面是「好看」，实质是一次 token 经济学操作——把「读一大段文字、自己在脑子里搭结构」替换成「直接拿到可操作组件」，复杂任务所需的对话往返次数随之下降。这正是「算账日」在交互层的落点：**界面在替模型省 token**。但它同时把 ChatGPT 从「对话框」往「应用生成器」推了一步——按钮、计算器、可编辑图表都是应用的原件。这条线和 10-07「主权日」里 Dots 常驻 Agent、Sign in with ChatGPT 把 12 亿周活变成应用商店分发渠道是同一条：对话即渠道之后，对话即应用。竞争对手的麻烦在于，可交互组件比纯文本更难被第三方客户端复刻——界面黏性第一次成了模型的护城河。

## 📦 Nous Research 估值 15 亿：开源 agent 的 2.5% 全球 token 用量怎么变现

**事件概要**：10 月 7 日，Nous Research 确认以 **15 亿美元估值**完成 9000 万美元 B 轮，Robot Ventures 领投，Nvidia、Union Square Ventures、Menlo Ventures、Samsung、以及 Trump Jr. 担任合伙人的 1789 Capital 参投；成立三年总融资 1.58 亿美元。新资金投向企业级「Hermes for Businesses」。

**关键细节**：

- **开源规模**：Hermes Agent 已被 clone 超 **2400 万次**，据其自身估算约占**全球 AI token 用量的 2.5%**
- **企业版卖点**：公司可部署处理多步工作流的自定义 agent，数据保持私有与安全——不经过第三方 API
- **收入**：2026 年 9 月中年化收入约 **$36M**，预计年底前突破 **$100M**
- **资本结构**：Nvidia（芯片）与 1789 Capital（政治关联）同时在场，是算力供应商在应用层的双向下注，也是开源 agent 第一次拿到这个量级的资本

**深度分析**：这是「算账日」在开源侧的答案。2.5% 的全球 token 用量不收 API 费，钱从哪来？答案是「企业版 + 私有部署」——Hermes for Businesses 卖的不是模型而是「数据不出门的主权」。这正好接住昨天「主权日」那条线：Mistral Large 4 卖「自己造」，Underdog 卖「自己跑」，Nous 卖「自己部署」，三件事是同一个主权诉求的三种产品形态。$36M → $100M 的指引意味着年化收入要在约一个季度内接近 3 倍增长——这是开源 agent 商业化第一次有可验证的收入数字，而不只是 GitHub star 与下载量。对闭源厂商它是反向压力：当最便宜的选择变成「把模型搬进自己机房按固定价格付费」，按 token 计价的护城河就被绕过了。

## 总结与展望：主权日之后，所有人都在算同一笔账

今天五条线看似分散——模型定价、企业采购、内容溯源、对话界面、开源融资——但把它们并排看，会发现是同一笔账的五个科目：

| 事件 | 栈层 | 算了什么账 | 付出的代价 |
|------|------|------------|------------|
| Claude Haiku 5.5 | 模型层 | 10 万 token 内单价 **-90%**，缓存读取减半 | Terminal-Bench 39.2% 仍低于 Sonnet 70.6%，复杂编码还得大模型 |
| Meta / 微软砍预算 | 采购层 | 员工月预算上限 **降 10 倍**，内部 Anthropic 支出预期降逾 1/3 | 探索空间关闭；Meta 28 天仍付 $1.05 亿，账单没跟着用户降 |
| SynthID 开放 | 溯源层 | 检测入口首次跨厂聚合、免费可用 | 每天 10 次 + 强制登录；Meta 与开放权重模型覆盖不到 |
| GPT-6 Intelligent UI | 交互层 | 用可操作组件减少对话往返 | 默认输出更「重」，需手动调低视觉量 |
| Nous / Hermes 融资 | 开源层 | 2400 万次 clone 变现，企业版私有部署 | 社区版继续免费，钱只从「数据不出门」那一端收 |

**共同主题**：昨天「主权日」解决的是「谁能不让别人插手」，今天五条线回答的是「自己干了，账单谁扛、怎么扛」。Anthropic 的答案是把单价砍到地板并给开发者发补贴；Meta 与微软的答案是把预算上限写进采购系统；Google 的答案是把溯源检测做成限量公共品；OpenAI 的答案是让界面替模型省 token；Nous 的答案是让企业为「不出门」付钱。五种算法指向同一个判断：**2026 年 AI 竞争的主战场，已经从「谁更聪明」转到「谁把每个 token 的账算得更清楚」**。

**6 条 6-12 月可验证硬指标**：

1. Haiku 5.5 上线 90 天后，`claude-haiku-5-5` 在公开模型排行榜与 Anthropic 控制台的调用量份额，应超过 Haiku 4.5 的历史峰值
2. 微软云与 AI 部门的月度人均 AI 支出，应在 2027 Q1 前稳定在 $10k 档位——若回升，说明自研替代未达预期
3. Meta 对 Claude Code 的 28 天滚动支出，应在 2027 H1 出现实质下降；若仍在 $1 亿档，说明「少用不等于少花」成了长期状态
4. synthid.com 上线 90 天的日检查量，以及因「连续查相似图片」被锁定账号的比例——后者是绕过工具开发的先行指标
5. Apple 加入 SynthID 伙伴名单的实际时间点（Google 只说「即将」），以及 Meta 是否从自家水印方案迁移——这决定检测网络的覆盖率天花板
